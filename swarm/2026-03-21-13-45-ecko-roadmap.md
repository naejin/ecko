## Consensus

# v0.7.0 "Observability" — debug mode, committed-file fix, placeholder detection

## Recommendation

v0.7.0 is a focused release: **make ecko's behavior visible and its stop-mode detection reliable**. 2 bug fixes, 3 infrastructure features, 1 new check. ~340 tests (up from 314).

### Priority 0 — Bug Fixes

**1. Fix `echo` to `printf` in `exit_plan_mode.sh`**

File: `hooks/exit_plan_mode.sh`

```bash
printf '%s\n' "~~ ecko ~~ Remember to include test steps for all code changes in this plan." >&2
```

**2. Fix `_get_modified_files` — add committed-but-recent changes**

File: `checks/runner.py`, function `_get_modified_files` (line 572)

Add a 4th git query:
```python
# Recently committed files (catch files committed during this session)
result = subprocess.run(
    ["git", "log", "--since=4h", "--diff-filter=ACMR", "--name-only", "--pretty=format:"],
    capture_output=True, text=True, cwd=cwd, timeout=10,
)
if result.returncode == 0:
    for line in result.stdout.strip().splitlines():
        if line:
            files.add(os.path.join(cwd, line))
```

All 4 syntheses converged on this being the highest-impact functional bug. The `--since=4h` heuristic is stateless, covers normal sessions, and degrades gracefully. `--diff-filter=ACMR` excludes deleted files.

### Priority 1 — Infrastructure

**3. Debug mode (`ECKO_DEBUG=1`)**

New file: `checks/debug.py` (~15 lines)

```python
"""Debug output for ecko — enabled via ECKO_DEBUG=1 environment variable."""
from __future__ import annotations
import os
import sys

_DEBUG = os.environ.get("ECKO_DEBUG", "") == "1"

def debug(msg: str) -> None:
    """Write a debug message to stderr if ECKO_DEBUG=1."""
    if _DEBUG:
        sys.stderr.write(f"~~ ecko ~~ debug: {msg}\n")
        sys.stderr.flush()
```

Instrument 8 points in `runner.py`:
1. Mode entry (`debug(f"mode={args.mode} file={args.file}")`)
2. Config load result
3. Language detection
4. Tool resolution
5. Layer 2 echo count
6. Modified file list in stop mode
7. Layer 3 tool dispatch
8. Final exit code

**4. `--files` CLI argument for stop mode**

File: `checks/runner.py`, modify `main()` and `run_stop()`

```python
parser.add_argument("--files", help="Comma-separated file list (overrides git detection in stop mode)")
```

`run_stop` signature:
```python

**5. Clean-sweep message and stop-mode timing**

When stop finds zero echoes:
```

### Priority 2 — New Check

**6. Placeholder detection (`placeholder-code`)**

New file: `checks/custom/placeholder_code.py` (~80 lines)

**Python (AST-based):**
- `pass` as sole body of non-abstract function/method
- `...` (Ellipsis) as sole body of non-abstract, non-stub function
- `raise NotImplementedError` as sole body of non-abstract function

**JS/TS (regex-based):**
- `throw new Error("not implemented")` or `throw new Error("TODO")`

**Exclusions:**
- `@abstractmethod`, `@overload` decorated functions
- Protocol class methods
- `.pyi` type stubs (already skipped by `_is_skippable_stub`)
- Test files
- Functions with `# ecko:ignore`

Wire into `_run_layer2_checks()`:
```python
if lang == "python" and not is_test_file(file_path):
    from checks.custom.placeholder_code import check_placeholder_code
    echoes.extend(check_placeholder_code(file_path))
```

Check name: `placeholder-code`. Register in `ecko.yaml.example` disabled_checks.

## Key Agreements

1. **The `echo` to `printf` fix is overdue.** Every synthesis flagged it. 1-line change.
2. **`_get_modified_files` has a real gap.** Committed files invisible to stop mode. Universal.
3. **Debug mode is the most impactful infrastructure addition.** Every synthesis included it.
4. **Clean-sweep message is essential UX.** Clean stop indistinguishable from "ecko didn't run."
5. **Session ledger is NOT ready for v0.7.0.** Stateless heuristic first.
6. **No new languages, severity, or structured output.** All premature.

## Resolved Trade-offs

**Session ledger vs. stateless heuristic:** Stateless `--since=4h` wins. Session ledger adds JSONL I/O, cleanup, and cross-invocation coordination to a tool where each hook is a fresh Python process.

**Self-correction tracking:** Deferred. Requires persistent state.

**Placeholder detection:** Included (3/4 syntheses). Conservative scope, real AI-coding failure mode.

**Debug module location:** Separate `checks/debug.py`. Different concern from echo formatting.

**Per-tool timing:** Overall elapsed in standard output, per-tool in debug only.

## Open Questions

1. **`--since=4h` duration** — long sessions could exceed it. Future `ECKO_SESSION_HOURS` env var.
2. **Placeholder FP rate** — needs 10-repo validation. If >5% FP, tighten or defer.
3. **ExitPlanMode hook value** — static string, no context. Worth revisiting.
4. **Non-git projects** — `_get_modified_files` silently returns empty. Debug mode surfaces it.
